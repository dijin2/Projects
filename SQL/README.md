# Covid-19 Data Exploration

This project explores global Covid-19 data using SQL.  
It demonstrates various analytical techniques to uncover insights such as infection rates, death percentages, vaccination progress, and continent-level breakdowns.

## 🛠️ Skills Used
- Joins  
- Common Table Expressions (CTEs)  
- Temp Tables  
- Window Functions  
- Aggregate Functions  
- Creating Views  
- Converting Data Types  

## 📂 Dataset
The analysis is based on two datasets:
- **CovidDeaths**
- **CovidVaccinations**

## 📊 Key Insights
- Likelihood of dying if infected with Covid  
- Percentage of population infected per country  
- Countries and continents with highest death counts  
- Global case and death trends  
- Vaccination progress compared to population  

## 🚀 How to Use
Run the SQL scripts in your preferred SQL environment (e.g., SQL Server).  
Each query is structured to highlight a specific aspect of the data.
