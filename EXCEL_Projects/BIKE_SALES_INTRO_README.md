##🚴 Excel Dashboard Project: Bike Buyers Analysis
This project showcases my ability to clean, transform, and visualize customer data using Microsoft Excel. I analyzed a comprehensive dataset of over 1,000 records to uncover patterns in bike purchasing behavior.
🔧 Key Steps:
- Data Cleaning: Removed duplicates, standardized categorical values, and ensured consistent formatting across fields like income, education, and commute distance.
- Feature Engineering: Created derived columns for age groups, income brackets, and commute categories to enhance segmentation.
- Pivot Table Analysis: Explored multi-dimensional relationships between bike purchases and variables such as marital status, occupation, education, region, and lifestyle indicators.
- Dashboard Design: Built an interactive dashboard with slicers, bar charts, and conditional formatting to allow dynamic filtering and highlight key trends.
📊 Key Insights:
- Customers with short commutes and mid-to-high income levels showed higher purchase rates.
- Pacific region buyers were more likely to purchase bikes than those in Europe.
- Occupation and education level played a significant role in purchase behavior, with professionals and graduates showing distinct trends.
🧠 Tools Used:
- Microsoft Excel (Pivot Tables, Slicers, Conditional Formatting, Charts)
- Data Cleaning & Transformation (Text-to-Columns, Data Validation, Logical Formulas)
