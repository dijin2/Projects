# US Airport Delays – Tableau Dashboard

This repository showcases an interactive **Tableau dashboard** built using the *US Airport Delays* dataset.  
The visualization provides insights into flight punctuality, delay causes, and cancellation trends across airlines and airports in the United States.

## 📂 Dataset
- Source: GitHub (US Airport Delays dataset)  
- Size: 21 columns, ~70,000 records  
- Contains flight arrival and delay data categorized by airline, airport, and delay causes:
  - Carrier delays  
  - Weather delays  
  - NAS (National Aviation System) delays  
  - Security delays  
  - Late-arriving aircraft delays  
- Includes cancellation reasons (airline, weather, security, etc.)

## 📊 Tableau Visualizations
The following visuals were designed in Tableau:

- **Airline Delay Percentage**  
  Shows the proportion of delayed arrivals per airline. Tooltips provide clear percentage values.

- **Delay Across Airport Regions (Map)**  
  Geographic visualization of delays across regions. Tableau automatically detected location fields, making map creation seamless.

- **Top 5 Airports by Cancelled Arrivals (Donut Chart)**  
  Highlights airports with the highest cancellations. Built using sets and hover interactions for clarity.

- **Monthly Trends of Delay Types Across Airports**  
  Interactive filter allows users to switch between delay types (carrier, weather, NAS, security, late arrivals). Titles update dynamically with filter selections.

- **Monthly Trends in Flight Arrival Delays and Cancellations**  
  Dual-axis chart combining bar and line visuals for better comparison of delays vs. cancellations.

## 🎯 Purpose
The Tableau dashboard is designed for **Airline Operations Managers** to:
- Monitor KPIs across airlines and airports  
- Identify root causes of delays  
- Track cancellation and diversion rates  
- Benchmark carrier performance  
- Support data-driven strategies to reduce disruptions
