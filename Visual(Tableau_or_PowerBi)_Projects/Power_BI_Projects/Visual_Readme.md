# ✈️ US Airport Delays Dashboard (Power BI)

This Power BI dashboard analyzes flight delay patterns across US airports using a dataset of over 70,000 flight records. It provides interactive visuals to help airline operations managers monitor performance, identify delay causes, and improve scheduling efficiency.

## 📊 Dashboard Highlights

### 1. Airline Delay Percentage
- Bar chart showing the percentage of delayed arrivals per airline.
- Labels are clearly visible on the chart for quick interpretation.
- Helps benchmark carrier performance and identify underperforming airlines.

### 2. Delay Across Airport Regions
- Map visualization displaying delay distribution across US airport regions.
- Location fields were manually configured to ensure accurate geographic mapping.
- Useful for identifying regional bottlenecks and weather-sensitive zones.

### 3. Top 5 Airports by Cancelled Arrivals
- Donut chart highlighting the airports with the highest cancellation rates.
- “Top N” filter applied to dynamically select the top 5 based on cancellation count.
- Enables targeted investigation into cancellation hotspots.

### 4. Monthly Trends of Delay Types
- Interactive chart showing delay types (Carrier, Weather, NAS, Security, Late Aircraft) over time.
- Custom DAX measure used to switch between delay types via slicer.
- Title updates dynamically based on selected delay type.
- Supports root cause analysis and seasonal trend identification.

### 5. Monthly Trends in Arrival Delays vs. Cancellations
- Dual-axis chart combining bar (delays) and line (cancellations).
- Axes are synchronized for consistent scaling and comparison.
- Reveals correlation between delay volumes and cancellation spikes.

## 🧰 Power BI Features Used
- Slicers for dynamic filtering
- DAX measures for conditional logic and title updates
- Tooltip enhancements for label clarity
- Copy-paste dashboard assembly for efficient layout
- Custom formatting for improved readability
